# PHP & MySQL CRUD App

A full-stack CRUD application built with PHP and MySQL, following Tania Rascia's tutorial, "Build a PHP & MySQL CRUD Database App From Scratch."

## Technologies

- PHP
- MySQL
- HTML
- CSS
- PDO (PHP Data Objects)

## Features

This project will support creating, reading, updating, and deleting user records.

## Development

The application uses MAMP for local PHP and MySQL development.
